# Brand assets

The "Pizza Magic!" mark (a pizza with a purple magic sparkle) and wordmark, generated by these dev-time scripts (Node, no packages):

- `node tools/brand/make-svgs.js <dir>` writes `logo.svg`, `logo-mark.svg` and `favicon.svg`.
- `node tools/brand/make-icons.js <dir>` writes `favicon.ico` (16, 32, 48 px), `apple-touch-icon.png` (180 px) and preview PNGs.

Copy the outputs into `src/PizzaMagic.Web/wwwroot/` (`favicon.*`, `apple-touch-icon.png`) and `wwwroot/images/` (`logo*.svg`). Both scripts share one geometry on a 64 x 64 grid; keep them in sync.

Colors: crust #E8A23B / edge #B5651D, cheese #FFD15C, pepperoni and "Pizza" #C0392B, sparkle and "Magic!" #7B3FBF.
